# Install Megatask for Codex CLI

Clone the public repository into a stable location, then run:

```sh
git clone https://github.com/MaxenceBouvier/megatask.git
cd megatask
python3 scripts/install-skills.py --target codex
```

Run `/skills` in Codex and select `megatask-preparation`. Restart if needed.
See [compatibility and removal](../docs/cli-compatibility.md) before launching a
campaign. The portable installer preserves bundled scripts and license notices.
