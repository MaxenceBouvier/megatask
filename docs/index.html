megatask

A queue of issues, a manager session, and workers that do the work.

What it is

megatask is a way to hand a coding agent a long list of tasks and come back to merged work. A manager session reads the queue, starts a worker session for each issue, checks what comes back, and merges it.

It ships as a Claude Code plugin, plus the guide that explains why each rule is there.

How it runs

  1. The spec is reviewed four ways before anything is built, so vague or unsafe requirements are caught early.
  2. The plan is executed by subagents, one task at a time, each one checked against the spec.
  3. A manager session drives worker sessions through a queue of issues and merges each result as it passes.

The free part

The plugins are open source under the MIT license. The code is on GitHub. To install them in Claude Code:

claude plugin marketplace add MaxenceBouvier/megatask
claude plugin install megatask@megatask
